OpenCart Demo Manual Testing Project

📌 Project Overview

This repository contains the complete **Manual Testing documentation for the OpenCart Demo e-commerce application**.

The objective of this project was to test the major functionalities of the OpenCart Demo website, identify defects, validate expected behavior, and prepare complete testing documentation.

The testing was performed using a **Black Box Testing approach**, focusing on validating the application's functionality from an end-user perspective.

🎯 Project Objectives

* Understand the functionality of an e-commerce web application.
* Prepare a structured Test Plan.
* Design and document Test Scenarios and Test Cases.
* Execute test cases and record the results.
* Identify, report, and track defects.
* Maintain a Requirement Traceability Matrix (RTM).
* Prepare a Test Summary Report.


🌐 Application Under Test

Application: OpenCart Demo

📂 Project Deliverables

This repository includes the following testing documents:

| Document            | Description                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------------- |
| Test Plan           | Defines the scope, objectives, approach, resources, and testing strategy.                               |
| Test Scenarios      | High-level scenarios created for different application functionalities.                                 |
| Test Cases          | Detailed test cases with test steps, test data, expected results, and execution status.                 |
| Test Execution      | Contains the execution results of the test cases.                                                       |
| Bug Report          | Documents the defects identified during testing.                                                        |
| RTM                 | Maps requirements and test cases to ensure test coverage.                                               |
| Test Summary Report | Provides an overall summary of testing activities and results.                                          |
| Screenshots         | Contains screenshots of the application, test documentation, execution results, and identified defects. |


🐞 Defects Identified

During testing, 6 defects were identified.

Some test cases were also marked as Blocked because the corresponding functionality could not be executed successfully.

Detailed information about the identified defects is available in the Bug Report, along with supporting screenshots.

🔄 Testing Process

1. Analyzed the OpenCart Demo application.
2. Identified the modules and functionalities to be tested.
3. Prepared the Test Plan.
4. Created Test Scenarios.
5. Designed detailed Test Cases.
6. Executed the test cases.
7. Recorded Actual Results and Test Status.
8. Identified and reported defects.
9. Prepared the Requirement Traceability Matrix (RTM).
10. Created the Test Summary Report.
